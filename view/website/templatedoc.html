React templates combined with Go provide a powerful solution for building dynamic web applications. By integrating these templates with a GraphQL API, you can efficiently fetch and display dynamic content. This guide walks you through the process of setting up and configuring the default React templates in our Go project, connecting them to a GraphQL, Go backend using Individual API keys for dynamic content, and deploying the entire application to Vercel for production-ready hosting.

Step 1:

Ensure the spurtcms adminsetup is available ready in your system. Check our pre-requisites and installation guideline for more details.

Step 2:

On the templates page,click the deploy button on your desired template in which you want to showcase your data.

Step 3:

Click on the button “Continue with github” to get signed up with github and install vercel.

Step 4:

Click on the button “Authorize Vercel”, then vercel will redirect you to the authentication page.On successful authentication you need to enter your api token key.

Step 5:

Now inside your spurtcmsAdmin account navigate to API keys,click on Action button and copy the default API token that we will be using for displaying our content.

Step 6:

Enter you api token and click on deploy button.Please wait for the deployment steps to get over without reloding or closing the page.Your can see the details as webpage click on the link below the Domains Heading.
