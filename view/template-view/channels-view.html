eCommerce Channel

Get started with ready-made fields like product name, description, and price. Want more? Add custom options such as “Special Price,” or ‘’Variants’’ or ‘’Product Specifications’’. Create a richer shopping experience. Plus, it’s built to grow with you—add more features as your store expands.

News Channel

Start with the essentials: title, description, and image. Need more details? Easily add fields like “Source,” “Author,” or “Publish Date” to give full context to each story. Designed to be flexible, so you can continue to add more features over time.

Event Listings

The basics—event title, description, and date—are ready to go. Add extra fields like “Speakers,” “Location,” and “Registration Link” to create an engaging event page. Scalable for adding more as your event portfolio grows.

Classifieds/Yellow Pages

Set up with core fields like listing title, description, and contact information. Enhance listings with “Category,” “Location,” or “Price Range” for better searchability. Ready for you to scale and add new features as needed.

Blog Channel

Begin with a straightforward setup: blog title, content, and featured image. Add fields like “Tags,” “Author Bio,” or “Related Posts” to enrich each article. Flexible enough to support additional customizations as your content grows.

Job Board

Default fields like job title, description, and company name are pre-set. Customize further with fields for “Location,” “Salary Range,” or “Application Deadline” to attract ideal candidates. Built to expand as your hiring needs evolve.
